## Decisions taken

- **The task was inferred** (note at the top); fourth run in a row without a task section.
- **The dependency on `main` was checked by the session, not assumed**: `git log` shows
  `9a29108 P0-08 send to all` merged at `1269b6f`.
- **`base` is set only for `vite build`**, so `npm run dev` stays at `/` and `npm run preview`
  serves the Pages path. One constant, `PAGES_BASE`, is the thing the custom-domain note
  points at.
- **Commit hash from git first, `GITHUB_SHA` second.** `actions/checkout` leaves a `.git`, so
  the workflow takes the first path; the second covers a build from an export without `.git`;
  `dev` is for everything else. Seven characters in both paths so the label is stable.
- **"Installed version" is the running code's version.** With `registerType: "prompt"` the
  running code is the installed one until the operator reloads, so there is one version to
  show, not two. The waiting build's version is not readable from the page; the banner says
  that one exists.
- **"Last checked" is session state**, like `clockTrust`, not a saved setting: the browser
  checks on every launch, so after a restart the first value is the launch itself. Set when the
  registration completes (that is the browser's own check) and after each completed explicit
  check; a failed check leaves it alone and shows why.
- **Reload happens only on the operator's click**, via the function `registerSW` returned.
  The generated `sw.js` activates only on the `SKIP_WAITING` message (checked in the build
  output); nothing in the app sends it without the click. This is the acceptance's "offer a
  reload, not swap silently".
- **The Pages one-time setting is documented, not scripted.** "Source: GitHub Actions" is a
  repository setting the workflow cannot make; `deploy/README.md` says so and names the error
  the `deploy` job shows until it is done.
- **Node 22 in the workflow.** `package.json` says `>=20.11`, Vite 7 needs 20.19+ or 22.12+;
  22 is the current LTS. The local run used Node 26.1.0.
- **No dependency added.** Prettier was run on the new files only, as in P0-07 and P0-08; the
  touched files differ from Prettier's output in line endings alone.
- Candidates for `docs/decisions.md`: the app is published on GitHub Pages from `main` by
  Actions; the version is `package.json` version + short commit + build time injected at build
  time; the service worker never takes over without the operator's reload.
