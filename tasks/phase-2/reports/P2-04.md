## Decisions taken

- **The compose card folds away once a batch is queued.** The task puts the compose card
  above the queue and asks for twelve queue rows at 720 px. The arithmetic does not allow
  both with the card open: 720 − 56 (bar) − 48 (gutters) = 616 px for the page; the queue card's
  chrome (padding, title, border) is 91 px and twelve dense rows with the header 419 px, which
  leaves 90 px for a compose card that holds a recipient list. So the card is open while the
  queue is empty, closes when a batch is stored (`onstored`; the operator watches the queue
  now), and "New message to many" in the queue's title opens it again; Hide in its own title
  closes it by hand. Flagged as a deviation from a plain stack; the document's "compose card
  on top" holds whenever the card is open.
- **Table rows are `--s-1` tall in padding** (32 px at 16 px; was `--s-2`, 40 px). Fifteen
  register rows and twelve queue rows at 720 px need it, and a data table is where the
  document wants density. The style guide's sample and the shortcuts card follow; the journal's
  rows keep `--s-2` (43 px), a slip is read, a table is scanned.
- **The handover's lists take the viewport** and each scrolls in its card, so the four cards
  are on the screen at 720 px whatever they hold; while a reply is open the layout lets go of
  the viewport height (the lists capped at 40 vh) rather than shrink the lists to their
  titles. The reply form opens *above* the lists, as the journal's compose card sits above its
  list, and closes on send.
- **The age is in the strip.** The old handover table had an Age column; `.rows` has no
  column for it, so the age is the last element of the strip (14 px, `--ink-2`), after the
  status chips, on every list that has a time.
- **Handover row actions are always shown** (`.rows-actions-always`): the page exists for
  the decisions on the rows, and hiding Retry / Send by courier / Close until hover would hide
  the point of the screen. The journal keeps hover.
- **Register toolbar: Print is icon-only** (`.btn-icon` with the label as `aria-label` and
  tooltip): with the five buttons' Danish words the toolbar wrapped to two lines at 1280 px,
  and the printer icon is the one of the five that reads without a word.
- **The register's Notes column is gone from the table** (the task's list: label, person,
  street, role, origin chip, key prefix, last heard); the notes are in the form and the
  pending table keeps them. Follow-up.
- **Origin as a neutral chip with a short word** ("issued" / "ad hoc" / "private"; the long
  form as tooltip): the task asks for a chip, and a chip of three words is a pill with a
  sentence. All three are grey — an origin is not a status.
- **Settings: a Save per card with typed values, switches at once.** Operator, Radio and Hub
  have a Save each (validation per card, the Saved toast); Clock, Text & contrast and Language
  apply at once as before; the Journal folder's buttons are the mirror's gestures. One
  Save for the whole page would make a wrong send gap block a name change.
- **An eighth card, Hub.** The task names seven; the hub URL (P0-01's placeholder for phase
  3) fits none of them and is editable, so it gets a card of its own between Radio and Text &
  contrast rather than a field in About. The device id moved to About (it is what this device
  is; read-only).
- **"Text & contrast"** replaces "Screen" as the card's name (the task's words; the key
  `settings.appearance` is gone).
- **The page width lives in `base.css`**: one `main` rule, 90 rem and the `--s-5` gutter
  (the document's page), no `.wide` switch; a screen that needs less lays itself out narrower
  (the settings column at 44 rem, left-aligned — the document forbids centred layouts with
  empty flanks). The journal's height calculation already assumed the `--s-5` gutter.
- **`position: relative` on the scrolling boxes**: see *Done*; a component fix that also
  removes the journal's page scroll with a long register. No journal file was touched.
- **Visually hidden page titles** on all five screens (the bar's navigation names the
  screen; the journal does the same since P2-03). The intro paragraphs went with them: the
  register's and the queue's were removed (their keys too), the radio's is the state card's
  first line.
- **`clearLog()` on the radio store** rather than a "cleared up to here" index on the page:
  the store caps the log at 200 lines and drops from the front, so an index would drift.
- **Prettier** was run on the new files and on every touched file; `SettingsPage.svelte` and
  `AdhocBatchForm.svelte` were unformatted on `main` and are rewritten whole, so they are
  formatted now (as P2-03 did with the journal page). `app/README.md` stays unformatted. Every
  changed file is LF.
- Candidates for `docs/decisions.md`: the compose card folding once a batch is queued; table
  rows at `--s-1`; a Save per settings card; the scrolling boxes positioned.
